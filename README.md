## 📖 项目简介

这是 Alexander James Carter 的个人网站，展示个人作品和内容分享。网站采用现代化的前端技术栈，支持多语言界面，具备响应式设计和 PWA 功能。

🌍 **访问地址**: [https://alexander.xin](https://alexander.xin)

## ✨ 主要特色

### 🎨 用户体验

- **响应式设计** - 完美适配桌面、平板和移动设备
- **多语言支持** - 支持中文、英文、意大利语、日语
- **PWA 支持** - 可作为原生应用安装到设备
- **深色/浅色主题** - 智能主题切换
- **无障碍设计** - 符合 WCAG 无障碍标准

### 🚀 技术特性

- **现代化前端技术栈** - HTML5, CSS3, ES6+
- **模块化架构** - 组件化的 CSS 和 JavaScript
- **性能优化** - 图片懒加载、代码压缩、CDN 加速
- **SEO 优化** - 完整的 meta 标签、结构化数据、网站地图
- **Google Analytics** - 集成流量分析

### 🎵 交互功能

- **音乐播放器** - 内置音频播放功能
- **图片画廊** - 响应式图片展示
- **智能聊天机器人** - AI 驱动的用户交互
- **诗词展示** - 集成今日诗词 API
- **日历功能** - 农历日历显示
- **二维码生成** - 便捷的分享功能

本项目使用 GitHub Pages 进行自动部署：

1. 推送代码到 `main` 分支

3. 通过自定义域名 `alexander.xin` 访问

### 本地开发环境

```bash
# 克隆项目
git clone https://github.com/AlexanderJ-Carter/AlexanderJ-Carter.github.io.git

# 进入项目目录
cd AlexanderJ-Carter.github.io

# 使用本地服务器运行（推荐使用 Live Server）
# 或者使用 Python 简单服务器
python -m http.server 8000

# 访问 http://localhost:8000
```

## 🔧 配置文件

### manifest.json

PWA 应用配置文件，定义应用名称、图标、主题色等。

### robots.txt

搜索引擎爬虫规则，控制页面索引行为。

### sitemap.xml

网站地图，帮助搜索引擎更好地索引网站内容。

### ads.txt

广告验证文件，用于 Google AdSense 验证。
