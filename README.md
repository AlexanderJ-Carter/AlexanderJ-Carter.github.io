## 站点亮点

- 多语言支持: zh-CN（默认）、zh-TW、en-GB、fr、ru
- 页面体验: 深浅色主题、滚动动画、无障碍优化
- 内容版块: 作品画廊、项目展示、时间线、Now/Uses、工具页
- 技术底座: Astro + Tailwind CSS + TypeScript
