## 概述

本项目使用基于路由的国际化系统，支持多种语言。通过 URL 路径区分不同语言版本。

### 特点

- ✅ 基于路由的语言切换
- ✅ SEO 友好（自动生成 hreflang 标签）
- ✅ 默认语言无需 URL 前缀
- ✅ 类型安全的翻译系统
- ✅ 易于添加新语言

---

#### astro.config.mjs

## 添加新语言

### 步骤 1: 更新 Astro 配置

编辑 `astro.config.mjs`：

```javascript
export default defineConfig({
  i18n: {
    defaultLocale: 'zh-CN',
    locales: ['zh-CN', 'zh-TW', 'en-GB', 'fr', 'ru', 'de'],  // 添加德语
  },
  integrations: [
    sitemap({
      i18n: {
        locales: {
          // ... 其他语言
          'de': 'de',  // 添加德语
        },
      },
    }),
  ],
});
```

### 步骤 2: 添加语言信息

编辑 `src/i18n/ui.ts`：

```typescript
export const languages = {
  // ... 其他语言
  'de': 'Deutsch',  // 添加德语名称
};
```

### 步骤 3: 添加翻译文本

在 `src/i18n/ui.ts` 的 `ui` 对象中添加：

```typescript
export const ui = {
  // ... 其他语言
  'de': {
    'site.title': 'Alexander James Carter',
    'site.description': 'Entdecken Sie Kreativität, teilen Sie Leben, zeichnen Sie wunderbare Momente auf',
    'nav.home': 'Startseite',
    'nav.gallery': 'Galerie',
    'nav.blog': 'Blog',
    'nav.about': 'Über',
    'nav.contact': 'Kontakt',
    // ... 所有需要的翻译
  },
} as const;
```

### 步骤 4: 创建语言路由

在 `src/pages/[lang]/` 目录下创建页面文件（如果还没有的话）。

示例：`src/pages/[lang]/about.astro`

```astro
---
import BaseLayout from '@/layouts/BaseLayout.astro';
import { getLangFromUrl, useTranslations } from '@/i18n/utils';

const lang = getLangFromUrl(Astro.url);
const t = useTranslations(lang);

export function getStaticPaths() {
  return [
    { params: { lang: 'zh-TW' } },
    { params: { lang: 'en-GB' } },
    { params: { lang: 'fr' } },
    { params: { lang: 'ru' } },
    { params: { lang: 'de' } },  // 添加德语路径
  ];
}
---

<BaseLayout title={t('about.title')} description={t('about.desc')} lang={lang}>
  <h1>{t('about.title')}</h1>
  <!-- 页面内容 -->
</BaseLayout>
```

### 步骤 5: 更新语言切换器

确保 Header 组件中的语言切换器包含新语言。

## 翻译指南

### 翻译键命名规范

使用点分隔的命名空间：

```typescript
'namespace.component.key': '翻译文本'
```

**示例**：

```typescript
// 全局
'site.title': '网站标题'
'site.description': '网站描述'

// 导航
'nav.home': '首页'
'nav.about': '关于'

// 页面特定
'home.hero.title': '首页英雄标题'
'about.bio.heading': '关于页面简介标题'

// 组件
'footer.copyright': '版权信息'
'button.submit': '提交按钮'

// 消息
'message.success': '成功消息'
'message.error': '错误消息'
```

### 翻译内容指南

#### 1. 保持一致性

```typescript
// ✅ 好的
'button.save': '保存'
'button.cancel': '取消'
'button.delete': '删除'

// ❌ 避免
'button.save': '保存'
'cancel': '取消'  // 命名不一致
'delete_btn': '删除'  // 命名格式不一致
```

#### 2. 使用占位符

```typescript
// ✅ 好的 - 使用参数
'message.welcome': '欢迎, {name}!'

// 使用时
t('message.welcome', { name: 'Alexander' })
// 输出: 欢迎, Alexander!
```

#### 3. 处理复数

```typescript
// 英语
'items.count': '{count} item | {count} items'

// 中文（无复数变化）
'items.count': '{count} 个项目'
```

#### 4. 保持简洁

```typescript
// ✅ 好的
'nav.home': '首页'

// ❌ 避免过长
'nav.home': '点击这里返回首页'
```

### 翻译工作流

```
1. 添加英文键和文本
   ↓
2. 翻译到其他语言
   ↓
3. 在组件中使用
   ↓
4. 测试所有语言版本
   ↓
5. 提交代码
```

## 使用翻译

### 在 Astro 组件中

```astro
---
import { getLangFromUrl, useTranslations } from '@/i18n/utils';

const lang = getLangFromUrl(Astro.url);
const t = useTranslations(lang);
---

<h1>{t('site.title')}</h1>
<p>{t('site.description')}</p>
```

### 在客户端脚本中

```typescript
// 从页面传递翻译
---
const translations = {
  save: t('button.save'),
  cancel: t('button.cancel'),
};
---

<script define:vars={{ translations }}>
  console.log(translations.save);
</script>
```

### 动态内容

```astro
---
const userName = 'Alexander';
const t = useTranslations(lang);
---

<p>{t('message.welcome').replace('{name}', userName)}</p>
```

### 语言切换链接

```astro
---
import { languages } from '@/i18n/ui';
const currentPath = Astro.url.pathname;
---

{Object.entries(languages).map(([lang, label]) => (
  <a href={lang === 'zh-CN' ? '/' : `/${lang}/`}>
    {label}
  </a>
))}
```

## 最佳实践

### 1. 完整性检查

确保所有语言都有相同的键：

```typescript
// ✅ 好的 - 所有语言都有
'zh-CN': { 'nav.home': '首页' }
'en-GB': { 'nav.home': 'Home' }
'fr': { 'nav.home': 'Accueil' }

// ❌ 避免 - 缺少翻译
'zh-CN': { 'nav.home': '首页' }
'en-GB': { 'nav.home': 'Home' }
'fr': { }  // 缺少 nav.home
```

### 2. 回退机制

```typescript
function useTranslations(lang: keyof typeof ui) {
  return function t(key: string) {
    return ui[lang][key] || ui[defaultLang][key] || key;
  }
}
```

### 3. 类型安全

```typescript
// 使用 TypeScript 确保类型安全
export const ui = {
  'zh-CN': {
    'nav.home': '首页',
  },
  'en-GB': {
    'nav.home': 'Home',
  },
} as const;

// TypeScript 会检查键是否存在
t('nav.home')  // ✅ 正确
t('nav.invalid')  // ❌ 类型错误
```

### 4. 文件组织

对于大型项目，考虑分割翻译文件：

```
src/i18n/
├── locales/
│   ├── zh-CN.ts
│   ├── en-GB.ts
│   ├── fr.ts
│   └── ru.ts
├── ui.ts          # 聚合所有翻译
└── utils.ts       # 工具函数
```

### 5. 日期和时间

```typescript
// 使用 Intl API 格式化
const date = new Date();
const formattedDate = new Intl.DateTimeFormat(lang).format(date);

// 示例
'zh-CN': '2024年12月7日'
'en-GB': '07/12/2024'
'fr': '07/12/2024'
```

### 6. 货币和数字

```typescript
// 使用 Intl.NumberFormat
const amount = 1234.56;
const formatted = new Intl.NumberFormat(lang, {
  style: 'currency',
  currency: 'CNY',
}).format(amount);

// 示例
'zh-CN': '¥1,234.56'
'en-GB': 'CN¥1,234.56'
```

## 常见问题

### Q: 如何处理复数形式？

A: 对于有复数变化的语言（如英语），可以使用条件判断：

```typescript
function pluralize(count: number, singular: string, plural: string) {
  return count === 1 ? singular : plural;
}

// 使用
const itemCount = 5;
const text = `${itemCount} ${pluralize(itemCount, 'item', 'items')}`;
// 输出: "5 items"
```

### Q: 如何处理 RTL 语言（如阿拉伯语）？

A: 在布局中添加 `dir` 属性：

```astro
---
const isRTL = lang === 'ar';
---

<html dir={isRTL ? 'rtl' : 'ltr'}>
  <!-- 内容 -->
</html>
```

### Q: 翻译缺失时怎么办？

A: 实现回退机制：

```typescript
function t(key: string) {
  return ui[lang][key] || ui[defaultLang][key] || key;
}
```

### Q: 如何翻译动态内容？

A: 使用模板字符串或替换：

```typescript
const message = t('message.welcome').replace('{name}', userName);
```

### Q: 如何组织大量翻译？

A: 按功能模块分组：

```typescript
export const ui = {
  'zh-CN': {
    // 全局
    'site.title': '...',
    
    // 导航
    'nav.home': '...',
    'nav.about': '...',
    
    // 首页
    'home.hero.title': '...',
    'home.hero.subtitle': '...',
    
    // 关于页
    'about.bio': '...',
    'about.skills': '...',
  },
};
```

### Q: 支持自动翻译吗？

A: 建议使用专业翻译服务或工具：
- Google Translate API
- DeepL API
- 人工翻译（推荐）
