## 💡 文档编写指南

想要贡献文档？请遵循以下指南：

### Markdown 格式

```markdown
# 一级标题 (主标题)

## 二级标题 (章节)

### 三级标题 (小节)

**粗体** - 强调重要内容
*斜体* - 次要强调
`代码` - 内联代码
```

### 代码块

使用语言标识符：

````markdown
```typescript
// TypeScript 代码
```

```astro
---
// Astro 组件
---
```

```bash
# Shell 命令
```
````

### 链接

```markdown
[链接文字](URL)
[相对链接](./ARCHITECTURE.md)
[锚点链接](#section)
```

### 列表

```markdown
- 无序列表
- 项目 2

1. 有序列表
2. 项目 2

- [ ] 待办事项
- [x] 已完成项目
```
