« Сейчас читаю » в ленте исчезает через дни. Нужна страница, которая растёт медленно: ясные маршруты, заметки под рукой, право убрать устаревшие книги.

`/reading-list` для этого — не bestseller-чарт и не affiliate-воронка, а карта для будущего меня.

## Что решает страница

1. **Меньше повторных ошибок** — та же тема, что читал и почему бросил, записано один раз.
2. **Проверяемые рекомендации** — ordered route, а не три названия с памяти.
3. **Чтение → творчество** — книги по фото / инженерии / эссе должны возвращаться в writing и gallery.

Ценность = **зачем книга на этом маршруте и что изменилось после**.

## Структура: маршрут > запись > рефлексия

- **Маршрут** — напр. «статический сайт», «свет», «длинный текст»
- **Запись** — название, автор, статус
- **Рефлексия** — конкретная; одна actionable фраза обязательна

## Удаление = доверие

« Планирую прочитать » три года отравляет список. Короткий честный список лучше декоративной эрудиции.

## Перекрёстные ссылки

Книга по perf → статья → build сайта. Список = индекс, не остров.

## Скучная реализация

Markdown или данные в Git, i18n, SSG. Без social-app с логином.

## Итог

Reading list — защита от амнезии ленты. Маршруты, actionable заметки, регулярные удаления — достаточно для долгой памяти, не для стены ссылок.
