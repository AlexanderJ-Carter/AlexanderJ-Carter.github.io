Bon design sans abonnement cher. Liste vérifiée en travail réel — pas un roundup générique.

## Couleur

- **Coolors** — palettes aléatoires, verrouillage, export CSS / Tailwind.
- **Realtime Colors** — ajuster sur une page mock, voir les relations live.
- **Color Hunt** — palettes communautaires par mood.
- **WebAIM Contrast Checker** — WCAG ; baseline accessibilité.

## Typographie

- **Google Fonts** — Noto Sans SC + Inter/DM Sans + display = stack sûr.
- **Fontpair** — paires éprouvées avec previews.
- **Typewolf** — inspiration fonts sur sites réels.

## Icônes

- **Lucide** — stroke cohérent ; bon fit Astro.
- **Phosphor** — six graisses, un set.
- **Tabler** — 5000+ line icons.
- **Iconoir** — set moderne avec composants framework.

## Illustration

- **unDraw**, **Humaaans**, **Open Peeps**, **Blush** — SVG recolorables, personnages modulaires.

## Photo

- **Unsplash**, **Pexels**, **Pixabay** — photos/vidéo libres ; Unsplash qualité, Pexels vidéo, Pixabay fallback large.

## CSS

- Générateurs glassmorphism, gradients, ombres lisses, **Animista** pour motion preset.

## Comment utiliser une liste

- **Un projet, un système** — une palette, une famille d’icônes, une ou deux polices.
- **Tokens d’abord** — couleur, espacement, radius avant multiplication de composants.
- **N’embarquer que l’utilisé** — moins d’assets, moins de maintenance.
- **Contraste et petite taille** — design pour tous, pas pour screenshots.

Collecter des liens est facile. **Choisir peu et avec cohérence** — c’est le métier.
