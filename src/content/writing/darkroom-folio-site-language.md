个人站很容易长成两种极端：要么像 SaaS 仪表盘，要么像空白 Notion 页。我在 2026 年的改版里选了一条中间路——**Darkroom Folio**：用暗房与冲印室的隐喻，把摄影、写作、工具页收进同一套视觉语法。

这不是换一套 Tailwind 主题色那么简单。它回答的是：**访客进入任意页面时，能否感到「仍在同一间编辑室」？**

## 三个锚点：Expose / Focus / Print

首页「暗房三法则」不是装饰文案，而是整站的决策顺序：

1. **Expose（曝光）** — 第一屏只给一件事：真实影像或一句主命题。统计条、六个入口、赞助位都往后排。
2. **Focus（对焦）** — 每个版块只做一件事：精选作品、近期写作、研究条、联系。标题用 folio 标记编号，而不是无限嵌套卡片。
3. **Print（出片）** — 细节在「冲印阶段」收敛：字体阶、边框、film-edge 分隔，而不是在第一屏堆动效。

任何新页面上线前，我会问：它属于曝光、对焦还是出片？如果三项都想做，通常说明信息架构还没收干净。

## 视觉 token：蓝晒纸，不是「深色模式反色」

Darkroom Folio 的底色灵感来自蓝晒（cyanotype）纸：冷中性、略带的化学感，而不是纯灰 `#111`。

实践约束：

- **强调色只给行动**：链接、主按钮、folio 标记。不给装饰描边到处染色。
- **深色模式单独调阶**：不是浅色 token 直接反转；正文对比度在暗色下更容易「糊成一片高级灰」。
- **film-edge 是章节标点**：像胶卷齿孔边，告诉眼睛「这一格结束了」，替代到处拉分割线。

摄影页用 contact-sheet 网格，写作页用 folio 页眉，工具页用 PageHero——容器不同，但**纸感、字阶、边距尺**共用。

## folio-mark：让导航像翻册子

`folio-mark` 是小号等宽标记（如 `01 · Studio`、`Dossier · AS`）。它承担两件事：

- **定位**：访客扫一眼知道自己在哪一卷；
- **降噪**：不需要每个区块一个大 icon + 渐变大标题。

About 页的个人档案区用 `02 · Person` 预留空白槽位——空态也是设计的一部分，用 `待写入` 而不是 Lorem ipsum，诚实且可维护。

## 与功能页的边界

工具页（Now、汇率、QR）允许更「面板感」，但仍沿用 PageHero + 同一 footer/header。Next 实验区可以更大胆，但通过 `/next` 门口与主站隔开——**主站是编辑室，实验区是暗房里的另一盏安全灯**。

MusicPlayer、广告位、Turnstile 验证都做成可开关：视觉系统要为「可能不存在」的模块留空，而不是假设它们永远在。

## 我刻意没做的事

- **没有全站卡片化**：说明性段落用标题 + 间距即可，少一层容器就少一层噪音。
- **没有 hero 粒子/光晕**：动效只保留有功能意图的（如 ExposureMeter 指向 Now），并尊重 `prefers-reduced-motion`。
- **没有把 i18n 文案塞进组件**：可见文字进 `src/i18n/pages/`，模板只负责结构——五种语言靠数据扩展，而不是复制五个 Astro 文件。

## 怎么判断「像不像同一间编辑室」

随机打开五个页面，遮住 logo：

- 字号阶梯是否一致？
- 主行动是否同样「少而清楚」？
- 空态是否同样克制，而不是有的页很满、有的页像没做完？

若答案是肯定的，Darkroom Folio 就在起作用；若某个页需要「特殊大屏效果」才能成立，通常说明它还没被收进语法里。

## 小结

Darkroom Folio 把个人站从「页面集合」变成「一册正在冲印的 folio」。Expose / Focus / Print 是工作流，蓝晒纸 token 与 folio-mark 是语法，空槽位与可开关模块是诚实维护的前提。下一版改动，我会先问它属于哪一格胶片——而不是先问该加什么动画。
