The right tools smooth workflow. This is not "best of 2026" marketing — what I actually kept after trying alternatives.

## Terminal

1. **Ghostty** — GPU-fast, quiet Mac terminal; migrated from iTerm2 for zero perceived scroll lag.
2. **Starship** — cross-shell prompt; Git branch, runtime versions, command duration in one TOML file.
3. **eza** — modern `ls`; `eza -la --git --icons` is my default.
4. **zoxide** — smart `cd`; `z project` beats retyping paths.

## Editor & Framework

5. **Cursor** — VS Code lineage with project-aware AI; I use it to mirror page templates across locales from one component pattern.
6. **Astro** — typed content collections, zero JS by default, fast builds; this site lives here.

## Hosting & Ops

7. **Cloudflare Pages** — CDN, HTTPS, `_headers` / `_redirects` in-repo; primary host with GitHub Pages as fallback.
8. **Vercel** — preview URLs per PR when I need shareable builds quickly.
9. **UptimeRobot** — free uptime pings; "site is down" email is enough for personal scope.

## Design

10. **Figma** — layout skeleton before code; spacing and type scale decided early.
11. **Realtime Colors** — palette on a fake page, not an abstract wheel.
12. **Coolors** — rapid exploration when direction is unclear.

## Writing & Thinking

13. **Obsidian** — local Markdown vault, Git-synced drafts and notes.
14. **Excalidraw** — rough diagrams for architecture and flows.
15. **Raycast** — launcher + clipboard history + small utilities under one shortcut.

## Selection Criteria

- **Fast cold start** — tools should not make you wait.
- **Declarative config** — one file beats ten GUIs.
- **Invisible when working** — good hosting does not notify on success.
- **Cross-platform where possible** — Rust CLI tools excel here.

Tools are means. The right pen disappears; you just write.
