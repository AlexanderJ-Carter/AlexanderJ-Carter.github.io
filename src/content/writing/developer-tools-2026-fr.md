Les bons outils lissent le workflow. Pas du marketing « best of 2026 » — ce que j’ai gardé après alternatives.

## Terminal

1. **Ghostty** — terminal Mac GPU-fast, scroll sans lag perceptible.
2. **Starship** — prompt cross-shell ; branche Git, runtimes, durée commande en TOML.
3. **eza** — `ls` moderne ; `eza -la --git --icons` par défaut.
4. **zoxide** — `cd` intelligent ; `z project` bat retaper les chemins.

## Éditeur & framework

5. **Cursor** — lignée VS Code + IA projet ; templates multilingues depuis un pattern composant.
6. **Astro** — collections typées, zéro JS par défaut, builds rapides — ce site vit ici.

## Hébergement & ops

7. **Cloudflare Pages** — CDN, HTTPS, `_headers` / `_redirects` en repo.
8. **Vercel** — preview URL par PR pour builds partageables.
9. **UptimeRobot** — ping uptime gratuit ; email « site down » suffit pour un perso.

## Design

10. **Figma** — squelette layout avant code.
11. **Realtime Colors** — palette sur fausse page.
12. **Coolors** — exploration rapide quand direction floue.

## Écriture & réflexion

13. **Obsidian** — vault Markdown local, Git-sync brouillons.
14. **Excalidraw** — schémas architecture.
15. **Raycast** — launcher + clipboard + petites utilités.

## Critères de choix

- **Démarrage rapide**
- **Config déclarative** — un fichier bat dix GUIs
- **Invisible quand ça marche**
- **Cross-platform** quand possible

Les outils sont un moyen. La bonne plume disparaît — tu écris.
