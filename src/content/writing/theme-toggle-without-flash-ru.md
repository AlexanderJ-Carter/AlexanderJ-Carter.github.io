Тёмный режим стал нормой, но качество реализации разное. Белая вспышка при каждом обновлении — проблема порядка скриптов, для посетителя это «сырой» сайт.

## Откуда вспышка

Светлый HTML по умолчанию → CSS → JS читает `localStorage` / `prefers-color-scheme` → класс `dark` на `<html>`. Виден тематический FOUC.

## Правильный порядок

**Первый кадр — уже финальная тема.** Крошечный синхронный скрипт в `<head>`: прочитать настройку, выставить класс. Не переносить его в конец бандла «для чистоты» — вспышка вернётся.

## Хранение

- Явный выбор light / dark / system.
- При «system» пересчитывать при загрузке, не застывать на вчерашней теме ОС.

## Токены и доступность

`html.dark` недостаточно — нейтрали, границы, код нужно проектировать отдельно. Уважать `prefers-reduced-motion`. Переключатель с доступным именем.

## Чеклист

1. Жёсткое обновление при тёмной ОС — экран сразу тёмный?
2. Ручной выбор сохраняется?
3. Пустое хранилище — разумный fallback?
4. Без JS — хотя бы одна читаемая тема?

На читательском сайте ночью вспышка при каждом переходе ощущается как «приложение», а не «документ».

## Итог

Решение до paint, правильные токены, разделение выбора пользователя и системы — три шага, большой тихий выигрыш.
