工具选对了，工作流就顺了。这篇文章不是泛泛的产品推荐，而是我过去一年真正在日常中使用、反复验证过的东西。有些是行业标配，有些是小众但好用到回不去的选择。

## 终端与 Shell

### 1. Ghostty

Mac 上的终端模拟器竞争激烈，但 Ghostty 凭借极致的性能和原生体验脱颖而出。GPU 加速渲染让滚动和输出速度快得没有感知延迟，配置文件用 Zig 写，简单直白。从 iTerm2 迁移过来之后，最大的感受是"安静"——没有花哨的功能，但该有的都有了。

### 2. Starship

Bash/Zsh 的 prompt 主题换了十几个，最后停在 Starship。Rust 写的，速度快到无感；配置用 TOML，跨平台统一；自动显示 Git 状态、语言版本、命令执行时间。不再需要折腾 PS1，一行配置搞定所有。

**个人使用**：我的 Starship 配置里加了一个自定义的 `directory` 组件，只显示最后两级路径，屏幕不会被长路径占满。在写项目的时候，它能立刻告诉我当前在哪个 Git 分支、有没有未提交的更改——省去了反复 `git status` 的习惯。

### 3. eza

`ls` 的现代替代品，用 Rust 重写。彩色输出、Git 状态标记、树形视图，一条命令搞定。`eza -la --git --icons` 是我最常用的组合，文件权限、大小、修改时间一目了然，还能看到哪些文件被修改过。

### 4. zoxide

`cd` 的智能版本。它会记住你访问过的目录，下次只需要 `z project` 就能跳转到 `~/code/personal/project`，不用一层层往上敲。用了一周之后你会发现，手动输入完整路径的感觉原始得难以接受。

## 编辑器与开发环境

### 5. Cursor

2026 年编辑器的答案。基于 VS Code，但内置了真正好用的 AI 辅助。不是那种按 Tab 自动补全的单行建议，而是能理解项目上下文、跨文件重构的协作伙伴。写 Astro 组件的时候，它能根据已有的模板推断出新的页面结构。

**个人使用**：我在 Cursor 里维护这个网站的全部代码。最常用的场景是让它根据我写的一个模板组件，生成其他语言版本的同构页面。省去了手动复制粘贴再改文案的时间。

### 6. Astro

严格来说它是框架不是工具，但 Astro 的开发体验值得专门提。Content Collections 的类型安全、零 JS 默认输出、View Transitions 的优雅过渡——每个特性都在解决一个真实的问题。从 Next.js 切过来之后，构建时间从 30 秒降到了 5 秒。

## Web 服务

### 7. Cloudflare Pages

部署静态站的首选。全球 CDN、自动 HTTPS、无限带宽免费额度、WebSocket 支持。和 GitHub Actions 配合做 CI/CD，推送到 main 分支自动构建部署，整个过程不到两分钟。Pages Functions 还能在边缘跑一些轻量的服务端逻辑。

**个人使用**：这个网站同时部署在 GitHub Pages 和 Cloudflare 上。Cloudflare 做主站，GitHub Pages 做回退。`_headers` 文件配置安全头，`_redirects` 处理旧 URL 迁移，一切都在代码仓库里管理。

### 8. Vercel

如果说 Cloudflare 是基础设施，Vercel 就是开发体验。Preview Deployments 让每个 PR 都有一个可访问的预览地址，团队协作的时候不用再问"你本地跑起来了吗"。对于个人项目，Serverless Functions 的免费额度绰绰有余。

### 9. UptimeRobot

网站监控的底线。免费版支持 50 个监控点，每 5 分钟检查一次，宕机了立刻发邮件通知。个人站不需要复杂的可观测性方案，能知道"网站挂了"就足够了。

## 设计与视觉

### 10. Figma

UI 设计的事实标准。Auto Layout、组件变体、设计令牌——2026 年的 Figma 已经是一个完整的设计系统工具。免费版对个人项目完全够用，本地文件存储也消除了对云端的依赖顾虑。

**个人使用**：我会在 Figma 里先画出组件的布局草图，再到 Astro 里实现。不是完整的视觉稿，更像是布局的骨架——确认间距、字号层级和颜色搭配。这种方式比直接写代码再反复调整高效得多。

### 11. Realtime Colors

Josh W. Comeau 的配色工具的另一种思路：不是生成调色板，而是让你在一个模拟页面上实时调整颜色，立刻看到效果。前景色、背景色、强调色、边框色——所有颜色之间的关系一目了然。选配色的过程从"在色轮上转"变成了"在真实场景里感受"。

### 12. Coolors

快速生成配色方案的工具。空格键生成随机方案，锁定喜欢的颜色继续调整，直到找到满意的组合。导出支持 CSS 变量、Tailwind 配置、SCSS 等格式，直接复制到项目里用。

## 生产力与写作

### 13. Obsidian

本地 Markdown 笔记，双向链接，图谱视图。不依赖云服务，数据完全在自己手里。写博客的初稿、记录技术笔记、整理读书摘要，全在一个 Vault 里。配合 Git 同步，多设备之间的切换无缝衔接。

### 14. Excalidraw

手绘风格的白板工具。不需要画得精确，反而因为线条的随意感让讨论更聚焦在想法本身。架构设计、流程梳理、UI 草图——任何需要"先画出来再说"的场景都适用。开源版本可以本地部署。

### 15. Raycast

Mac 上的启动器替代品。剪贴板历史、窗口管理、颜色拾取、编码转换、正则测试——所有小工具都集成在一个快捷键里。不再需要单独安装一堆小应用，`Cmd + Space` 解决一切。

## 选择工具的标准

这些工具能留在我日常使用清单里，不是偶然的。它们有几个共同点：

- **启动快**：工具不应该让你等待。Ghostty 的冷启动时间不到 100ms，Starship 的 prompt 渲染几乎零延迟。
- **配置简单**：能用一个文件搞定的事情不需要 GUI。eza、zoxide、Starship 都是声明式配置。
- **不打扰**：好的工具是透明的。你不会注意到它在运行，但它一直都在。Cloudflare Pages 构建成功后甚至不发通知——因为没有消息就是好消息。
- **跨平台一致**：在 Windows 和 macOS 上有相同或相似的体验。Rust 工具链在这方面做得尤其好。

工具只是工具。但选对了工具，就像选对了笔——你不用再想着"这笔好不好写"，而是直接开始写。
