Язык по умолчанию — zh-CN на `/`; также zh-TW, en-GB (`/en/`), fr, ru. Ловушка: одна строка навигации в пяти файлах, длинные статьи только на одном языке, путаница для SEO.

## URL

- `zh-CN` → `/about/`
- Остальные → `/zh-TW/about/`, `/en/about/` и т.д.

Без префикса для основного языка; `/en/` вместо `/en-GB/` в пути — точная локаль в `hreflang`.

## Три типа текста

1. **Глобальный UI** — `src/i18n/ui.ts`
2. **Страницы** — `src/i18n/pages/*.ts`
3. **Длинные тексты** — `src/content/writing/*.md` с `lang:`

Принцип: менять nav без статей. Честная пометка «статей на этом языке пока нет» лучше машинного filler.

## hreflang и canonical

Canonical на себя; alternate + `x-default` (здесь на корень zh-CN). Генерировать из layout пакетно.

## Тонкие routes, толстые templates

`src/pages/` только выбирает язык и рендерит Template.

## Частичный контент

Не все языки покрывают все статьи — нормально. Индекс фильтруется по `lang`; без автоперевода ради объёма.

## Итог

Мультиязычность — архитектура: стабильные URL, текст по слоям, явный SEO. Делается один раз, масштабируется лучше пяти отдельных сайтов.
