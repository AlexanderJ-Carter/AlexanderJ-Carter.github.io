好的设计不一定需要昂贵的工具。这篇文章收集了我日常使用的免费设计资源——每一个都经过实际项目验证，不是简单的列表堆砌。按类别整理，方便按需取用。

## 配色工具

### Coolors

**地址**：coolors.co

快速生成配色方案的工具。按空格键随机生成，锁定满意的颜色继续探索。支持导出为 CSS 变量、Tailwind 配置、SCSS 等格式。当你对配色没有明确想法的时候，这是最好的起点。

### Realtime Colors

**地址**：realtimecolors.com

在模拟的真实页面上调整颜色——前景、背景、强调色、边框、卡片——立刻看到组合效果。比在空白画布上选颜色直观得多。Josh W. Comeau 的色彩理论课程也值得一看。

### Color Hunt

**地址**：colorhunt.co

社区驱动的配色灵感库。每天更新热门方案，可以按标签（_pastel_、_vintage_、_neon_ 等）过滤。适合在项目初期寻找配色方向。

### Contrast Checker (WebAIM)

**地址**：webaim.org/resources/contrastchecker

输入前景色和背景色，计算对比度是否满足 WCAG 标准。无障碍设计的基本工具。不只是"能不能看清"，而是"所有人都能不能看清"。

## 字体

### Google Fonts

**地址**：fonts.google.com

免费字体的首选来源。Noto Sans SC 做中文正文、Inter 或 DM Sans 做英文界面、Playfair Display 做标题——这些组合经过大量项目验证，安全且好看。支持按语言、风格、字重筛选。

### Fontpair

**地址**：fontpair.co

不知道哪些字体搭在一起好看？Fontpair 提供了大量经过验证的字体搭配方案，按风格分类（_Serif + Sans-Serif_、_Display + Sans-Serif_ 等），每个方案都有实际效果预览。

### Typewolf

**地址**：typewolf.com

字体灵感站点。展示真实网站上使用的字体方案，附带分析和推荐。当你在 Google Fonts 的列表里迷失方向时，来这里看看别人怎么做的。

## 图标

### Lucide

**地址**：lucide.dev

线条风格图标库，Fork 自 Feather Icons 但持续更新。图标设计统一、线条粗细一致、支持 SVG 和 React 组件。Astro 项目里的首选图标方案。

### Phosphor Icons

**地址**：phosphoricons.com

提供六种粗细变体（_thin_、_light_、_regular_、_bold_、_fill_、_duotone_）的图标库。同一套图标可以在不同场景下使用不同风格，保持视觉一致性的同时提供灵活性。

### Tabler Icons

**地址**：tabler.io/icons

超过 5000 个开源 SVG 图标，线条风格，2px 描边。数量多、覆盖面广，适合需要大量图标的项目。每个图标都有代码直接复制。

### Iconoir

**地址**：iconoir.com

开源图标库，风格简洁现代。支持 React、Vue、React Native、Flutter 等多种框架的组件导入。每个图标都有像素级完美的对齐。

## 插画

### unDraw

**地址**：undraw.co

风格统一的矢量插画库，可以自定义主色调。所有插画保持同一视觉语言，不会出现"东拼西凑"的感觉。适合在关于页面、空状态、引导页使用。

### Humaaans

**地址**：humaaans.com

可自由组合的人物插画组件库。不同的头、身体、姿势可以混搭，适合需要"多样化人群"的场景。设计风格轻松友好。

### Open Peeps

**地址**：openpeeps.com

手绘风格的人物插画库，由 Pablo Stanley 设计。线条随性但不粗糙，风格独特。适合个人项目或需要一点幽默感的页面。

### Blush

**地址**：blush.design

艺术家创作的插画集合，支持在线自定义颜色和元素。免费版可以下载 PNG 和 SVG。每个系列的插画风格不同，可以按项目气质选择。

## 图片素材

### Unsplash

**地址**：unsplash.com

高品质免费照片库。摄影师社区贡献，质量远超一般素材站。搜索功能强大，_collection_ 功能可以按主题浏览。个人站和商业项目都可以免费使用。

### Pexels

**地址**：pexels.com

和 Unsplash 类似的免费照片和视频素材站。搜索体验流畅，视频素材是它相比 Unsplash 的优势。无需署名即可使用。

### Pixabay

**地址**：pixabay.com

免费图片、矢量图、插画、视频的综合素材站。覆盖面广，适合找不到特定素材时的补充搜索。CC0 协议，使用自由度高。

## CSS 工具

### Glassmorphism CSS Generator

**地址**：glassmorphism.com

毛玻璃效果生成器。调整模糊度、透明度、背景色，实时预览效果并复制 CSS 代码。毛玻璃效果用得好很漂亮，用得差很油腻——这个工具帮你控制参数。

### CSS Gradient

**地址**：cssgradient.io

渐变色生成器。支持线性渐变和径向渐变，可以添加多个色标、调整角度和位置。生成的 CSS 代码直接可用。

### Smooth Shadow

**地址**：shadows.brumm.af

多层阴影生成器。好的阴影不是单个 `box-shadow`，而是多层不同偏移和模糊的叠加。这个工具帮你一步步调整出自然柔和的阴影效果。

### Animista

**地址**：animista.net

CSS 动画库。提供大量预设动画效果（_fade in_、_slide in_、_bounce_、_scale_ 等），在线预览并生成代码。适合快速添加入场动画和交互反馈。

## 如何使用这些资源

收集资源不是目的，善用资源才是。几点建议：

- **克制选择**：一个项目选一套配色方案、一套图标库、一两种字体。混搭越少，视觉越统一。
- **先定系统**：在开始设计之前，先把颜色、字体、间距、圆角这些基础变量定义好。之后的每一步都在系统内操作。
- **少即是多**：图标只需要覆盖你实际用到的。字体只需要标题和正文两三种粗细。资源越精简，维护成本越低。
- **关注无障碍**：每次选颜色的时候检查对比度。每次选字体的时候考虑在小尺寸下的可读性。好的设计不是只给设计者看的。
