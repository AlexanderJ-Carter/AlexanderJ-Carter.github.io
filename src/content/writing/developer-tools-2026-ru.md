Правильные tools сглаживают workflow. Не marketing « best of 2026 » — что осталось после alternatives.

## Terminal

1. **Ghostty** — GPU-fast Mac terminal, scroll без perceptible lag.
2. **Starship** — cross-shell prompt; Git branch, runtimes, duration в TOML.
3. **eza** — modern `ls`; `eza -la --git --icons` по умолчанию.
4. **zoxide** — smart `cd`; `z project` beats retyping paths.

## Editor & framework

5. **Cursor** — VS Code lineage + project-aware AI; multilocale templates из одного component pattern.
6. **Astro** — typed collections, zero JS default, fast builds — этот сайт здесь.

## Hosting & ops

7. **Cloudflare Pages** — CDN, HTTPS, `_headers` / `_redirects` in-repo.
8. **Vercel** — preview URL per PR для shareable builds.
9. **UptimeRobot** — free uptime pings; email « site down » enough для personal scope.

## Design

10. **Figma** — layout skeleton до code.
11. **Realtime Colors** — palette на fake page.
12. **Coolors** — rapid exploration когда direction unclear.

## Writing & thinking

13. **Obsidian** — local Markdown vault, Git-sync drafts.
14. **Excalidraw** — rough architecture diagrams.
15. **Raycast** — launcher + clipboard + utilities под одним shortcut.

## Критерии выбора

- **Fast cold start**
- **Declarative config** — one file beats ten GUIs
- **Invisible when working**
- **Cross-platform** where possible

Tools — means. Хорошее перо исчезает — ты просто пишешь.
