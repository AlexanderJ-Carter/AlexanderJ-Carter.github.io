Good design does not require expensive subscriptions. This list is what I reach for in real work — verified, not a generic roundup.

## Colour

- **Coolors** (coolors.co) — randomise palettes, lock colours, export CSS variables / Tailwind.
- **Realtime Colors** (realtimecolors.com) — tune colours on a mock page, see relationships live.
- **Color Hunt** (colorhunt.co) — community palettes by mood tags.
- **WebAIM Contrast Checker** — WCAG contrast math; accessibility baseline.

## Typography

- **Google Fonts** — Noto Sans SC + Inter/DM Sans + display face is a safe stack.
- **Fontpair** — proven pairings with previews.
- **Typewolf** — real-site font inspiration and analysis.

## Icons

- **Lucide** — consistent stroke icons; good Astro fit.
- **Phosphor** — six weights for one glyph set.
- **Tabler** — 5000+ line icons, broad coverage.
- **Iconoir** — clean modern set with framework components.

## Illustration

- **unDraw** — unified vector style, recolourable.
- **Humaaans** — mix-and-match people parts.
- **Open Peeps** — hand-drawn character library.
- **Blush** — artist collections, export SVG/PNG.

## Photography

- **Unsplash**, **Pexels**, **Pixabay** — free photos/video; Unsplash for quality, Pexels for video, Pixabay as wide fallback.

## CSS Helpers

- **Glassmorphism generator** — tune blur/opacity without greasy defaults.
- **CSS Gradient** — linear/radial with copy-paste code.
- **Smooth Shadow** — layered shadows that look natural.
- **Animista** — preset CSS motion for entry/hover when needed.

## How to Use a Resource List

- **One project, one system** — one palette, one icon family, one or two typefaces.
- **Define tokens first** — colour, spacing, radius before components multiply.
- **Ship only what you use** — fewer assets, lower maintenance.
- **Check contrast and small-size readability** — design for everyone, not screenshots.

Collecting links is easy. **Choosing sparingly and consistently** is the craft.
