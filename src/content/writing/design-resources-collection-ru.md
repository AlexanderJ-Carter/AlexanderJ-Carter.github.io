Хороший дизайн не требует дорогих подписок. Список проверен в реальной работе — не generic roundup.

## Цвет

- **Coolors** — случайные палитры, lock, export CSS / Tailwind.
- **Realtime Colors** — на mock-странице, связи live.
- **Color Hunt** — community palettes по mood.
- **WebAIM Contrast Checker** — WCAG; baseline a11y.

## Типографика

- **Google Fonts** — Noto Sans SC + Inter/DM Sans + display = safe stack.
- **Fontpair** — проверенные пары с preview.
- **Typewolf** — font inspiration с реальных сайтов.

## Иконки

- **Lucide** — consistent stroke; хорош для Astro.
- **Phosphor** — шесть весов, один set.
- **Tabler** — 5000+ line icons.
- **Iconoir** — modern set с framework components.

## Иллюстрация

- **unDraw**, **Humaaans**, **Open Peeps**, **Blush** — recolorable SVG, modular characters.

## Фото

- **Unsplash**, **Pexels**, **Pixabay** — free photo/video; Unsplash quality, Pexels video, Pixabay wide fallback.

## CSS

- Glassmorphism generators, gradients, smooth shadows, **Animista** для preset motion.

## Как пользоваться списком

- **Один проект — одна система**: одна palette, одно icon family, один–два шрифта.
- **Tokens first** — color, spacing, radius до размножения components.
- **Ship only what you use** — меньше assets, меньше maintenance.
- **Contrast и мелкий размер** — design для всех, не для screenshots.

Собрать ссылки легко. **Выбирать мало и последовательно** — это craft.
