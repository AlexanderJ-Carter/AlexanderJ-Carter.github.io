安全漏洞披露政策

我们重视网站安全，欢迎安全研究者负责任地报告发现的安全漏洞

最后更新日期：2025年12月4日

政策概述

我们致力于保护用户数据和网站安全。如果您发现了我们网站的安全漏洞，我们鼓励您通过负责任的方式向我们披露，以便我们能够及时修复问题。

我们承诺
  • 认真对待每一个安全报告
  • 在收到报告后24小时内确认回复
  • 保护报告者的身份和提供的信息
  • 在修复后公开感谢贡献者（如您同意）

适用范围

本政策适用于以下域名和服务：

  • 主域名：alexander.xin
  • 子域名：*.alexander.xin
  • GitHub Pages：alexanderj-carter.github.io
不包括
  • 第三方服务和外部链接
  • 社交媒体账户
  • 其他不属于我们直接控制的服务

报告指南

为了帮助我们快速理解和修复问题，请在报告中包含以下信息：

基本信息

  • 漏洞类型和严重程度评估
  • 受影响的URL或功能
  • 详细的重现步骤
  • 潜在的影响描述

技术细节

  • 请求和响应示例
  • 截图或视频演示
  • 使用的工具和技术
  • 建议的修复方案（可选）

处理流程

1 报告接收

24小时内确认收到报告

2 初步评估

3-5天内完成初步分析

3 漏洞修复

根据严重程度制定修复计划

4 公开致谢

修复完成后更新致谢页面

法律保护

对于遵循本政策的安全研究活动，我们承诺：

  • 不会对研究者采取法律行动
  • 不会向执法部门报告研究活动
  • 与研究者合作解决发现的问题

研究者必须遵循负责任的披露原则，不恶意利用漏洞，不访问或修改他人数据。

测试限制

允许的测试

  • 自动化漏洞扫描（合理频率）
  • 手动安全测试
  • 社会工程学测试（仅限技术层面）

禁止的行为

  • 拒绝服务攻击（DoS/DDoS）
  • 访问、修改或删除他人数据
  • 恶意破坏网站功能
  • 进行物理攻击或社会工程
  • 公开披露未修复的漏洞
