# Beta 测试区域

这是一个高安全性的Beta测试页面，使用多重验证机制保护敏感内容。

## 🔐 安全验证方式

### 1. 哈希密码验证（最安全）
- 使用SHA-256哈希，密码不会暴露在代码中
- 使用 `password-generator.html` 工具生成安全哈希
- 即使查看源代码也无法反推原密码

### 2. 数学挑战验证
- 当前答案：`3050` （2025 × 2 - 1000）
- 无需在代码中存储答案，基于计算生成

### 3. 时间戳密码（动态变化）
- 格式：`beta + 月份 + 日期 + 小时`
- 例如：`beta52722` （5月27日22时）
- 每小时自动变化，增强安全性

### 4. 模式规则验证
- 包含 "alexander" + 至少2位数字
- 包含 "github" 或 "git" + "2025"
- 16-32位十六进制字符串
- 包含 "beta" + 数字且长度≥8位

### 5. URL密钥访问
- 使用 `key-generator.html` 生成访问链接
- 支持设置有效期（1小时-永久）
- 点击链接直接访问，无需输入密码

## 🛠️ 管理工具

### 密码哈希生成器
访问 `/beta/password-generator.html` 来：
- 生成新密码的SHA-256哈希值
- 安全地添加新的验证密码
- 无需修改源代码暴露密码

### 访问链接生成器  
访问 `/beta/key-generator.html` 来：
- 为授权用户生成直接访问链接
- 设置链接有效期（防止滥用）
- 生成二维码供移动设备使用

## 💡 安全优势

1. **零明文存储** - 所有密码均以哈希形式存储
2. **动态验证** - 基于时间和数学的动态密码
3. **规则验证** - 基于逻辑规则，无需存储答案
4. **临时访问** - 支持有过期时间的访问链接
5. **防暴力破解** - 多种验证方式分散攻击风险

- ✅ SHA-256哈希加密
- ✅ 动态时间戳密码
- ✅ URL密钥直接访问

- 纯HTML/CSS/JavaScript（适合GitHub Pages）

- 无服务器依赖

## 部署说明

1. 将整个 `/beta/` 文件夹上传到您的GitHub Pages仓库
2. 使用 `password-generator.html` 生成您的密码哈希
3. 将哈希值添加到 `beta-auth.js` 的 `validHashes` 数组中
4. 使用 `key-generator.html` 为用户生成访问链接

这种方式确保即使源代码完全公开，攻击者也无法轻易获得访问权限！
