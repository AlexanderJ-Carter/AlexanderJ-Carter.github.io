⚡ 快速开始

1. 创建 Cloudflare Worker：

  • 访问 Cloudflare Dashboard
  • 创建新的 Worker，命名为 beta-auth
  • 复制 cloudflare-worker.js 的内容到 Worker

2. 创建 KV 存储：

  • 在 Workers & Pages 中创建 KV namespace
  • 命名为：BETA_USERS
  • 在 Worker 设置中绑定 KV

3. 更新 API 地址：

// 在 user-auth.js 中更新这行： this.apiBase = 'https://beta-auth.您的用户名.workers.dev/api';

🔐 默认配置

  • 邀请码： beta2025
  • JWT 有效期： 24 小时
  • 密码加密： SHA-256

🧪 测试步骤

  1. 完成上述部署步骤
  2. 访问 登录页面
  3. 使用邀请码 beta2025 注册测试账户
  4. 登录并验证功能
  5. 检查 Cloudflare KV 中的用户数据

📞 需要帮助？

如果遇到问题，请检查：

  • Cloudflare Worker 是否正确部署
  • KV 命名空间是否正确绑定
  • API 地址是否更新正确
  • 浏览器控制台是否有错误信息
