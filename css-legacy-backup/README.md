# Legacy CSS 备份

该目录是样式重构前 `css/` 目录的完整拷贝，仅用于历史对照与紧急恢复。

## 使用说明

- **请勿** 在此目录中进行日常开发或引用新的资源。
- 所有页面应使用新的分组目录结构下的样式文件。
- 若需要回溯旧实现，可在这里查阅原始文件或手动复制回去。

## 恢复旧版样式

如需快速恢复至重构前的样式结构，可在仓库根目录执行：

```bash
./scripts/restore-legacy-css.sh
```

脚本会：

1. 将当前的 `css/` 目录重命名备份到 `css-refactored-时间戳/`；
2. 把本目录的内容完整复制回 `css/`。

若不希望使用脚本，也可以手动将 `css-legacy-backup/` 中的文件复制到 `css/` 下。

保持该备份有助于在未来检视差异或定位潜在问题。若确认不再需要，可在后续版本中删除。
